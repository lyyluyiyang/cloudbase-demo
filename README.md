# CloudBase 演示项目

这是一个使用腾讯云开发 CloudBase 构建的演示项目。

## 功能特性

- 用户认证
- 云函数调用
- 云数据库操作
- 云存储文件管理

## 技术栈

- 前端：Vue 3 + Vite
- UI：Tailwind CSS
- 后端：CloudBase 云函数
- 数据库：CloudBase 云数据库

## 快速开始

```bash
# 安装依赖
npm install

# 本地开发
npm run dev

# 构建生产版本
npm run build
```

## 部署说明

项目使用 CloudBase CLI 进行部署，详细步骤请参考 [部署文档](./docs/deployment.md)。
